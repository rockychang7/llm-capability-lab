    运行参数怎么读

    Provider
    提供模型的公司或平台。
    Model
    真正参与生成的模型名称。
    Mode
    运行时使用的推理档位；unknown 表示当时没有记录。
    Prompt / version
    输入任务及其版本号，相同版本才适合横向比较。
    Generated at
    生成时间；unknown 表示没有可靠记录，因此不做猜测。
    Entrypoint
    打开这份原始结果时使用的入口文件。
