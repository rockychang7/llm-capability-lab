# 01 · 一键点火，火箭升空

**版本**：v2

**变更**：v1 只有三句话，没有说明火箭的样子、点火过程、升空过程和终点。v2 把这些都写清楚了：火箭的外形与材质、发射场、点火与起飞的先后顺序、升空途中尾焰、天空和分离的变化，以及最终到达的位置（近地轨道）。

**测试能力**：单页面前端动画与视觉特效，包括写实的火箭绘制、粒子与光照、多阶段时间编排、镜头跟随和场景过渡，以及对一份详细需求的完整落实。

## 原始 Prompt

以下代码块是发送给模型的完整内容，保留原始措辞：

```text
给我实现一个单文件 HTML 页面：画面里有一枚立在发射台上的火箭，点击“点火”按钮后，火箭依次完成点火、起飞、穿越大气层、一二级分离，最后进入近地轨道。整个过程要像一场连续的现场直播：镜头不中断，动作流畅，细节写实。

# 一、火箭长什么样

画一枚现代两级液体运载火箭（外形参考猎鹰 9 号这一类），写实风格，不要卡通、扁平或简笔画。

- 比例：箭体细长，总高约为直径的 12 倍。火箭要显得高大，占画面高度的一半以上。
- 结构自上而下：尖拱形整流罩、二级箭体、颜色略深且带加强筋的级间段、一级箭体、底部发动机舱。
- 一级的细节：顶部有四片折叠收拢的栅格舵，箭体两侧贴着四条收起的着陆支腿，发动机舱能看到至少三个黑色钟形喷管和管线。
- 材质：主体是白色涂装，局部是拉丝金属色和黑色。圆柱面要有明暗渐变（一侧受光，一侧背光），再加上横向的焊缝环线、竖向的面板接缝、铆钉和高光带。发动机舱周围有被烟熏黑的痕迹。不能是一整块平涂的颜色。
- 低温细节：液氧贮箱位置有一片白霜，箭体侧面不断冒出白色的液氧蒸汽，飘一段就散掉。
- 标识：箭体上有虚构的任务名称、编号和徽标，不要使用真实机构或公司的标志。
- 光照：设定一个明确的光源（比如黎明时从左侧斜射过来的太阳），箭体要有对应的受光面和背光面，塔架的泛光灯会在箭体上落下暖色光斑。

# 二、发射场

- 时间是黎明前后：天空从深蓝渐变到地平线上的橘粉色，有少量带边缘光的云，还留着几颗没有消失的星星。
- 地面是混凝土发射台，中间有导流槽（把火焰引向两侧的凹槽），台面上有焦痕和油渍。远处是平原或海岸线和几座储罐，空气里有一层薄雾，越远越淡。
- 火箭一侧立着钢桁架的勤务塔，能看清桁架结构、平台和爬梯，顶部有闪烁的红色航空障碍灯，几根脐带臂（给火箭输送燃料和供电的管线臂）伸出来连着箭体。旁边还有避雷塔和泛光灯。
- 待发时画面是“活”的：灯在闪，水汽在飘，云在缓慢移动，不是一张静止的图片。

# 三、点火与起飞

点击“点火”后，下面这些阶段按顺序发生，每个阶段都要有看得出来的区别。从点击到离开发射台大约 12 到 15 秒。

1. 倒计时：屏幕上从 T-10 开始倒数。T-7 时发射台开始喷出大量水雾（用来降噪的水幕），白色水汽从台面两侧涌出来。临近点火时，脐带臂依次摆开，脱离箭体。
2. 点火（T-3 到 T-0）：发动机先冒出几簇小而亮的橙色火苗，接着迅速点燃，汇成稳定的火柱。喷口处是接近白色的高亮核心，往外依次是黄、橙、红，边缘是半透明的烟。火焰打在导流槽上被劈开，向两侧喷射，翻涌成一团团灰白色烟云，贴着地面向外扩散，慢慢把箭体底部藏进烟里。火光把发射台、塔架、云底和箭体下半截都映成暖橙色，并且随着火焰强弱闪动。
3. 离台（T+0）：箭体被释放后先缓缓抬起，要有“很重”的感觉，前 2 到 3 秒才完全离开发射台，随后不断加速。起飞时整个画面轻微震动，震动随推力变化，离地后逐渐减弱。
4. 离开塔架后，火箭开始向画面一侧缓缓倾斜（重力转弯：为了入轨，箭体会逐渐从竖直转向水平），角度随时间平滑变化。

# 四、升空

从离台到入轨约 40 到 50 秒。

- 镜头：离台后从固定镜头变成跟随镜头。火箭保持在画面中偏下的位置，地面和塔架向下移出画面。不允许切镜头、黑屏或闪帧。
- 尾焰随高度变化：低空时火焰短、亮、粗，里面有明暗相间的菱形冲击波（马赫盘）；越往上空气越稀薄，火焰变长、变宽、变淡，接近真空时变成又大又淡的蓝白色锥形羽流。
- 尾迹：低空时留下一条浓密的白色烟迹，被高空风吹得弯曲、扩散，越高越细越淡，最后消失。
- 天空：颜色随高度由浅蓝过渡到深蓝，再到近乎全黑。云层从火箭旁边依次向下掠过，穿云的瞬间画面略显朦胧。星星随着天空变暗逐渐出现，地平线上浮现一条发光的大气层细线。
- 最大动压点（Max-Q，火箭承受气动压力最大的时刻）：火箭短暂抖动，接近音速时箭体周围出现一圈白色的凝结云环，随后恢复平稳。
- 一二级分离：一级发动机关机，尾焰熄灭，火箭滑行片刻；级间段分离，一级箭体向后翻转着脱落，在画面里变小并下落；二级发动机随即点火，火焰换成淡蓝白色，几乎没有烟，只有一束干净、向外扩张的真空羽流。
- 整流罩分离：整流罩两瓣向两侧张开脱落，露出里面的卫星。

# 五、最终到达哪里

终点是近地轨道，高度约 400 公里。入轨后的收尾（从卫星分离到显示“入轨成功”）约 10 到 20 秒。

- 随着高度增加，画面逐渐过渡为太空。入轨时下方是一道弧形的地球：蓝色海洋、白色云层和陆地，边缘有一层发光的薄薄大气；一侧太阳正在升起，带出镜头光晕；另一侧是夜半球，能看到零星的城市灯光。上方是深黑的太空和满天繁星。
- 卫星缓缓脱离二级箭体，展开两块太阳能电池板，慢慢飘远。二级发动机关机，镜头缓缓拉远，画面安静下来，和发射时的轰鸣形成对比。
- 屏幕上显示“入轨成功”，以及最终的遥测数据（高度约 400 km，速度约 7.7 km/s，任务时间）和一个“重新发射”按钮。点击后回到发射前的初始画面，可以反复发射。

# 六、界面与交互

- 初始状态只有一个醒目的“点火”按钮，状态显示“待命”。点击后按钮变为不可点击。
- 发射过程中有一个简洁的遥测面板：任务时间（T- 或 T+）、高度（km）、速度（km/s）、当前阶段（倒计时、点火、起飞、Max-Q、级间分离、入轨）。数值要和画面里的运动一致，连续变化，不能跳变。
- 页面不能出现滚动条，窗口大小变化时自动适配，手机竖屏下构图和按钮也要完整可用。
- 可选加分项：用 Web Audio 现场合成音效（倒计时提示音、发动机轰鸣、分离声），必须在点击之后才开始播放，并提供静音开关。

# 七、技术要求

- 只产出一个 HTML 文件，CSS 和 JavaScript 全部内联，不引用任何外部资源（图片、字体、视频、音频、CDN 一律禁用）。画面用 Canvas、SVG、CSS 或 WebGL 现场绘制，2D 或 3D 都可以，以画面写实为准。
- 用 requestAnimationFrame 驱动，按真实经过的时间（而不是帧数）推进动画，让 60Hz 和 120Hz 的屏幕上速度一致；适配高分屏。
- 支持 prefers-reduced-motion：此时减弱震动和闪烁，但仍然可以完整发射。
- 从点击“点火”到入轨成功，总时长约 60 到 90 秒。

完成后请自己逐项检查：火箭第一眼就像一枚真的两级火箭；点火、离台、加速、尾焰变化、分离、入轨全部出现；全程是一个连续镜头，没有跳变；终点画面明确，并且可以重新发射。
```
