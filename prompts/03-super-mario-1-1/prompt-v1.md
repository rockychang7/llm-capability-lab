# 任务
用一个单独的 HTML 文件，尽可能忠实地复刻 1985 年 FC 版《超级马里奥兄弟》的第一关（World 1-1）。
目标是让玩过原版的人一上手就觉得"就是这个味道"：关卡布局、操作手感、规则都要贴近原版。

# 技术约束
- 只用 HTML + 原生 JavaScript + Canvas，不用任何第三方库
- 不加载任何外部图片、音频、字体。所有角色和地形都用代码画成 16×16 的像素图，音效用 Web Audio API 合成方波和噪声
- 游戏内部分辨率是 256×240（和原版一样），再按整数倍放大显示，并关闭图像平滑（image-rendering: pixelated），保证像素清晰
- 游戏逻辑固定每秒 60 帧（固定时间步长），画面用 requestAnimationFrame 渲染。这样在 120Hz/144Hz 屏幕上速度也不会变快
- 所有物理数值集中放在一个 CONFIG 对象里，方便调整

# 坐标约定
- 一格 = 16×16 像素。屏幕宽 16 格、高 15 格
- x 从关卡最左边算起，第 0 格开始。y 从屏幕最上面算起，第 0 行开始
- 地面占最下面两行（y=13 和 y=14）
- "低层砖块行"是 y=9（离地 4 格，小马里奥正好能顶到）；"高层砖块行"是 y=5
- 关卡全长约 212 格

# 关卡数据格式（必须遵守）
关卡要用一个字符串数组表示，一行字符串就是地图的一行，一个字符就是一格。在代码里用注释写清每个字符代表什么，例如：
  . 空  # 地面  B 砖块  ? 问号块  S 台阶硬块  [ ] { } 管道四个角  F 旗杆  C 城堡
这样我能直接在代码里看到地图，也方便自己改。

# 敌人布置（x 为大约位置）
- 栗子怪（Goomba）：x≈22、40、51、52.5、97、98.5、114、115.5、124、125.5、128、129.5、174、175.5
- x=80~87 那排高层砖块上面站着两只栗子怪
- 绿色乌龟（Koopa）：x≈107
- 敌人只有进入屏幕后才开始移动。碰到墙或管道会掉头；走到平台边缘会直接掉下去（绿乌龟也会）

# 操作和物理手感（原版数值，单位：像素/帧，按 60 帧算）
- 方向键左右移动，Z 跳跃，按住 X 跑步并发射火球
- 走路最高速度 1.5625，跑步最高速度 2.5625
- 走路加速度 0.0371，跑步加速度 0.0557
- 松开方向键时减速 0.0508；反向急转（刹车滑步）时减速 0.1016，并显示刹车动作
- 起跳速度：水平速度慢时 4.0，跑起来时 5.0
- 上升阶段一直按着跳跃键，重力约 0.125（跳得高）；松开跳跃键，重力变成约 0.4375（跳得低）。实现"按得越久跳得越高"
- 下落最快速度 4.5
- 空中可以微调左右方向，但改不了大方向
- 镜头只能往右走，不能往回卷。马里奥走到屏幕中间偏左时开始卷屏；他不能走出屏幕左边缘

# 角色状态
- 小马里奥 16×16，大马里奥 16×32，火焰马里奥（换配色，能发火球，同屏最多 2 个，火球落地会弹跳）
- 小马里奥吃蘑菇变大；大马里奥吃火焰花变火焰；受伤降一级，并有约 2 秒闪烁无敌
- 大马里奥蹲下时碰撞框变矮
- 无敌星：约 10 秒，角色变色闪烁，碰到敌人直接消灭敌人
- 小马里奥顶砖块，砖块只会弹一下；大马里奥顶砖块会碎成 4 块碎片飞散
- 顶一个方块时，站在它上面的敌人会被顶翻消灭

# 敌人规则
- 栗子怪：被踩会压扁，停留一下后消失
- 乌龟：被踩后缩进壳里；再碰一下壳会被踢出去高速滑行，能撞死路上的敌人，碰到墙
- 从侧面或下面碰到敌人，马里奥受伤
- 连续踩敌人（中间没落地），分数依次是 100、200、400、500、800、1000、2000、4000、5000、8000，再往后每次奖励 1 条命

# 分数和界面
- 顶部一行显示：MARIO 和分数（6 位数）、金币数、WORLD 1-1、TIME 剩余时间
- 时间从 400 开始倒数，大约每 0.4 秒减 1；时间到了马里奥死亡
- 金币 200 分，踩栗子怪 100 分，砖块碎掉 50 分，蘑菇/火焰花/星星各 1000 分
- 集满 100 枚金币奖励 1 条命
- 抓旗杆：抓得越高分数越高（从下到上依次是 100、400、800、2000、5000）
- 抓到旗杆后：马里奥沿杆滑下，旗子降下，马里奥自己走进城堡，剩余时间按每 1 点 50 分转换成分数
- 掉进坑或者被敌人打死：播放死亡动画（跳一下再掉出屏幕），扣 1 条命，重新开始这一关
- 有标题画面、"WORLD 1-1 / 剩余命数"过场画面、GAME OVER 画面

# 画面风格

- 马里奥要有站立、走路（3 帧循环）、跳跃、刹车、蹲下、抓旗杆、死亡这些动作帧
